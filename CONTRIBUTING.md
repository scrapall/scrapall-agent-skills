# Contributing

Thanks for helping improve the Scrapall agent skills.

- Found a wrong param, broken example or unclear workflow? Open a **Bug report** issue.
- Need a platform or endpoint we do not cover? Open an **Endpoint request** issue.
- Pull requests that fix docs or examples are welcome. Keep examples reading the key from `SCRAPALL_API_KEY`; never commit a real key.
- `skills/` and `examples/` are generated from the public API spec, so we may port your fix into the generator.
